## 3. Module Boundary Diagnosis

Diagnosis: `scripts` is a mixed-responsibility implementation-support boundary. It is not a legitimate domain module boundary by itself. Some subfamilies are legitimate thin harness facades, but the directory as a whole is an accidental catch-all for Make-owned child commands, shared harness libraries, scheduler internals, generation helpers, release evidence tooling, local dev wrappers, and target-local tests.
