## 3. Workbook Boundary Diagnosis

Diagnosis: `internal/modules/auth` is a mixture of a legitimate auth/account/admin HTTP facade, auth service/application logic, and shared cross-module auth utilities. It is not a workbook facade, view/projection orchestration layer, transport-adjacent workbook adapter, workbook mutation coordinator, or permanent home for timeline, projections, revisions, collaboration, imports/tabular ingest, entities/indicators, evidence, links, saved views, or view-contract logic.

The only workbook-adjacent behavior found is indirect:

- session resources include incident membership summaries, which the web shell can use for landing/workbook access decisions;
- bootstrap tokens are explicitly rejected for `/ws/v1/*`;
- session revocation notifies `WSHub`, which closes affected session-bound sockets.
