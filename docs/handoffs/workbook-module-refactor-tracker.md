## 3. Module Boundary Diagnosis

The current target is a **mixed-responsibility package**. It contains a potentially legitimate thin workbook-surface facade, but it is also an accidental catch-all mutation coordinator, a view/projection orchestration layer, a transport-adjacent adapter, a persistence-adjacent adapter, and a misplaced home for logic owned by other source modules. It is not a frontend shell/controller or grid-vendor implementation layer.

Core 03 `REQ-03-011` is the controlling architectural finding: workbook presentation and transport provide interaction and navigation surfaces; that surface does not make workbook the owner of source-record mutations, projection materialization, saved-view lifecycle, revision conflict semantics, or collaboration publication. This is a planning finding, not an implementation decision or authorization to move code.
