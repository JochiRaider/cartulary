authorized execution of the refactor plan. They do not create product behavior,
public compatibility, harness behavior, or claim-publication authority. Product

adopted owner named by the applicable row. If this tracker conflicts with an

Checkpoint protocol for every row:

1. Confirm the predecessor is `DONE` and mark the row `IN_PROGRESS`.
2. Change only that independently reversible slice.
3. Run its focused validation.
4. On failure, retain and record the run root, diagnose the failure, repair it
   within the same rollback unit, and rerun the identical failed gate. Do not
   start a later workstream while the active gate is failing.
5. Do not repeat an unchanged failing command without a concrete diagnosis,
   repair, or environment recovery. Preserve every superseded failure root.
6. Mark the row `BLOCKED` only for an owner contradiction, missing authority,
   or external dependency that cannot be repaired within the repository.
7. On success, record files, substantive behavior, commands, run roots, risks,
   rollback unit, and next row; mark the row `DONE`.
8. Run `make lint-markdown` and `git diff --check`.
9. Only then mark the next row `IN_PROGRESS`.

### 2.4 Interface and construction decisions

- `workbook.NewQueryProvider` accepts the query function, rejects nil, and
  returns the closed `QueryProvider` interface. Its implementation is private.
- The create, patch, conflict, clipboard, bulk, linked-note, and supersede
  constructors accept unnamed function signatures and retain their current
  nil validation. The exported callback type names are deleted.
- Restore-probe registry signatures use
  `internal/platform/workbookprobe.Registration` and
  `internal/platform/workbookprobe.Result` directly. Tests use the platform
  constants directly. Workbook continues to own registry validation and
  execution.
- `ContributionCatalogInput` contains projection descriptors, query, create,
  patch, conflict, action requirements, and action contributions. Construction
  validates the entire input and deep-copies caller-owned slices and keys before
  publishing immutable indexes.
- `workbookassembly.ContributionDependencies` groups database, projection
  descriptors and ports, owner facades, conflict services, Revisions, and
  Collaboration dependencies. Private per-owner builders contribute to one
  explicit aggregate; source semantics remain outside Workbook.
- Active assembly constructors for Assessment, Artifact, Task/Decision,
  startup, conflict idempotency, record-target resolution, and conflict-token
  decoding remain. Their production and owner-test callers provide continuing
  value; duplicating that composition elsewhere is outside this iteration.
- The large mutation-contract and catalog files MAY be split into cohesive
  private files as part of WS-21 and WS-22, but package behavior and the
  approved public-internal surface MUST remain unchanged beyond the named
  constructor cleanup.
