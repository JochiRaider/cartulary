## Diagnosis and correction

`emptyRelationshipStyle` supplied `--ct-colors-ink-tertiary` (`#64748B`, computed `rgb(100, 116, 139)`) to both “No items” and the retained “Draft” note. The empty Tags inspector had a completed serious Axe color-contrast finding. A bounded pre-change rendered assertion measured the same foreground against its actual opaque `--ct-colors-surface-1` background (`#111318`, `rgb(17, 19, 24)`) at **3.90:1**. Grid Axe contrast checks were incomplete, so they were not interpreted as passes or violations.

The local style now uses the existing `--ct-colors-ink-muted` (`#CBD5E1`, computed `rgb(203, 213, 225)`) for both cues, retiring tertiary ink for these consumers. Both cues have the same ordinary-text requirement and painted background. The 12px grid typography, 14px inspector typography, row dimensions, explicit Add and the retained-draft note remain intact. The approved muted/surface-1 pair measures **12.52:1** in the editor grid and Tags inspector. Viewer cells add the Grid Adapter's read-only stripe; the regression reads its computed gradient color and alpha, checks both stripe and unstriped paint over surface-1, and records a worst-case **11.16:1**. Source inspection found density selection changes sizing and typography but does not add a density-specific paint layer to these cues.

The browser regression is part of the existing lifetime scenario. It measures actual computed text and ancestor paint layers for editor Hosts/Identities/Tags empty cells and retained Draft cues, the empty Tags inspector, and read-only viewer empty and retained cues. It fails on unexpected paint, opacity or gradient composition instead of trusting a nearest-ancestor background. It also exercises column hide/restore, explicit reveal and Add reactivation, exact retained raw text, and absent viewer Add controls. It does not serve as a general contrast framework.
