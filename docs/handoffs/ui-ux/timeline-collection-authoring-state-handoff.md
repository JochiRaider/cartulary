## Diagnosis and change

The previous Grid Adapter cell-state path classified `!isGridColumnEditable(column)` as read-only. Timeline Hosts, Identities and Tags intentionally have `grid_editable=false` and no scalar editor, while their action-payload collection routes are writable. Thus an authorized cell displayed read-only hatching, a read-only marker and `aria-readonly=true` beside a working Add control. The focused production browser assertion first failed on Hosts with `aria-description="Read-only Hosts"`; the seeded editor review also observed all three contradictory AX labels beside Add.

Timeline column assembly now declares `authoringPresentation: "explicit_action"` only for collection bindings whose typed route is patch-writable with `writeKind="action_payload"`. `GridColumn` exposes this optional presentation descriptor. Grid Adapter resolves read-only presentation from current interaction authority, scalar eligibility and that descriptor; owner-supplied read-only cell state still dominates. The same resolver is used by the production grid and its test-support renderer. This supersedes scalar editability as the sole read-only presentation classifier for declared action cells. `isGridColumnEditable` still governs scalar mutation and navigation eligibility. Timeline collection `gridEditable=false`, `contractWritable=false` and absent scalar editors remain intact.

The production paths changed are `apps/web/src/workbook/timeline/components/useTimelineColumnAssembly.tsx` and `packages/grid-adapter/src/{core.ts,semanticCapabilities.ts,SemanticDataGrid.tsx,test-support.tsx}`. Focused tests changed under the corresponding Timeline and Grid Adapter owners, with authored row titles in `tools/test_families/{module.timeline,package.grid_adapter}.json` and its generator-owned `tools/execution_topology_render_index.json` projection.

Authorized committed collection cells now use the saved/active/pending/conflict state presentation applicable to their current state, without a false read-only cue. Ordinary selection still selects; Add opens raw entry. Viewer and closed-incident modes retain read-only hatching, markers, descriptions and no Add control. Existing Grid Adapter consumers without the descriptor retain their prior default. Read-only extension grids remain read-only. No request, draft, focus, mutation, schema, persistence or dependency interface changed.
