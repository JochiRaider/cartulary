## Before, after, and decisions

- Before: the Filters dialog forwarded bubbled Arrow/Home/End to menu navigation; only the lower range input occupied its operand registry slot. Pointer-acquired focus did not update the helper's active key. Cancel/Apply closed without requesting invoking-control focus return. A pre-change focused row failed on prevented ArrowDown and lost focus after an operand disappeared. A pre-change production Chromium row showed ArrowDown left the lower comparison at `gte` rather than advancing to `gt`.
- After: the shared helper has an opt-in form mode. Native controls retain Arrow/Home/End and interior Tab; only boundary Tab wraps, and Escape uses the existing composition, modifier, and prevented-event guards. Focus events identify the registered element, and each render reconciles removed or disabled destinations. Filters registers all four range controls and only the current operand shape. Add focuses Field; chip Edit focuses Operator. Escape, Cancel, Apply, and editing removal return to the surviving invoking control or existing trigger fallback. Outside focus departure closes without stealing its destination.
- Retired: menu-style key interpretation in this form and the incomplete range registry. Retained: the shared overlay focus/blur and restoration owner, genuine menu roving in its other consumers, current filter draft/operator/validation model, filter-only clear, overflow entries, and explicit Apply submission. The helper's menu mode remains its default. No parallel focus owner or timer was added.
- The common decision is whether registered items behave as menu choices or native form controls. An additional form dialog can opt into the same boundary without copying key policy. Leaving the gap would keep native editing unreliable and require per-control focus workarounds.
- Compatibility: no route, schema, query argument, server canonicalization, saved-view, authorization, grid-editing, or retained-authoring change. No migration or compatibility adapter is needed. Rollback is the authored helper/dialog/test/catalog change and regeneration of the derived browser manifest/topology index through `make generate`.
