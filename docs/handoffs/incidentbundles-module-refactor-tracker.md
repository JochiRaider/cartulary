## 3. Module Boundary Diagnosis

The permanent boundary diagnosis is: **keep `incidentbundles` as the thin public owner of whole-incident portability orchestration, while reducing concrete peer coupling and avoiding an unproven broad physical split**. It is a legitimate application/service facade, bundle and projection orchestration layer, mutation coordinator, transport-adjacent adapter, persistence-adjacent adapter, and mixed-responsibility package. It is not an accidental owner of Timeline, Entities, Indicators, Evidence semantics, Links, Saved Views, view-schema semantics, frontend controller state, test-util behavior, imports/tabular ingest, or grid-vendor integration.
