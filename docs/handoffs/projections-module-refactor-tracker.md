## 3. Module Boundary Diagnosis

Architectural finding: `internal/modules/projections` is a legitimate permanent workbook-projection subsystem, but it is a mixed-responsibility package internally. It is simultaneously a view/projection orchestration layer, persistence-adjacent derived-table adapter, generic query/materialization engine, provider registry, restore-rebuild implementation, and telemetry boundary. It is not an accidental catch-all for source-domain behavior.
