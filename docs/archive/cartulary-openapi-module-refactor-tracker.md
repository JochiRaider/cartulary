## 3. Module Boundary Diagnosis

The target is a legitimate canonical delivery artifact, a transport-adjacent
contract surface, and a mixed-responsibility aggregate. It is not evidence for
a permanent `cartulary-openapi` domain or application module. It contains no
runtime orchestration to move; rather, it combines contracts whose behavior is
implemented and owned elsewhere. As an ownership boundary it is an accidental
catch-all.
