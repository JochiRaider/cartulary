# Testing Harness Recovery Harness Lifecycle Map

## Document Role

This S5 artifact reconstructs caller-visible harness lifecycles from source,
scripts, manifests, retained-artifact readers, and S2 through S4 controlling
inputs. It records phases, emitted outputs, terminal states, partial states,
cleanup expectations, and consumers without changing or executing harness
behavior.

## Classification Rules

- A lifecycle starts at a caller-visible entrypoint and ends when that entrypoint
  returns a final exit status.
- Terminal states include pass, product assertion failure, harness operational
  failure, usage/configuration failure, timeout, cancellation/interruption,
  cleanup failure, partial success with failed child, and source-limited unknown.
- Partial-completion states are linked to `PCS-*` rows when setup, child work,
  reporting, or cleanup can complete only partly.
- Machine-consumed outputs are linked to `OI-*`, `CONS-*`, and `SCHEMA-*` rows.
- Runtime-sensitive cleanup, readiness, timeout, parent-death, and reaper claims
  remain `source_limit` unless S5 observed them through selected artifacts or
  non-mutating command output.

## Checklist Support

| Field | Value |
|---|---|
| Status | `complete` |
| Blockers | Broad gates, service-backed/browser/Docker/Compose/reset/cleanup runtime behavior, CI provider annotations, and controlled failure bundles were not executed or unavailable. |
| Findings | Major lifecycle findings are represented by `LIFE-0001` through `LIFE-0015` and linked to `OI-*`, `CONS-*`, `SCHEMA-*`, `PCS-*`, and `FAIL-*` rows. |
| Source limits | Existing and linked `SL-*` rows cover absent CI workflows, unexecuted runtime behavior, stale retained artifacts, failure-only schemas, platform assumptions, and cleanup/reaper completion. |
| Ambiguities | Existing and linked `AMB-*` rows cover reset-route authority, package-script status, local-dev persistence, public env precedence, supported platform profile, and external cache cleanup. |
| Handoff notes | S6 can consume lifecycle phases and partial states for timing, cleanup, race, and resource analysis; S8 must decide authority-boundary rows. |
| Evidence status | Rows use `observed`, `observed/source_limit`, or `source_limit`. |
| No-change confirmation | This file records recovery documentation only and does not alter harness behavior. |
