# Testing Harness Recovery Environment Contract Observations

## Document role

This S4 artifact records environment-variable defaults, pass-through behavior,
configuration assumptions, secrets, and network assumptions observed while
recovering service and resource lifecycle rules. It is recovery evidence only.

S4 did not run an override matrix. Unless a row states a direct assignment or
validation rule from source, cross-layer precedence remains
`TODO: precedence_unknown` and is tracked by `AMB-0012`.

## Environment observations carried forward

- `AMB-0012` remains open: S4 records static assignments and env reads, not a complete precedence matrix.
- Default test credentials are local harness/dev credentials and must not be reclassified as production secret policy.
- Direct package scripts can bypass Make-provided result roots, scheduler limits, and some worker defaults.
- S7 maintainer decision `MD-S7-0010` adopts source-observed environment variables and defaults for documentation, but explicitly leaves cross-layer precedence unresolved. Do not replace `TODO: precedence_unknown` with a normative precedence rule without a future owner decision or controlled evidence.
- S7 maintainer decision `MD-S7-0011` records WSL/Linux as the primary observed environment and Linux portability as a practical intent. It does not create a non-Linux support matrix or close missing-tool source limits.
