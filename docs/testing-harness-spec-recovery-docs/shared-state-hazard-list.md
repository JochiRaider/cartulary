# Testing Harness Recovery Shared State Hazard List

## Document role

This S3 artifact records fixture, artifact, cleanup, and shared-state hazards
that later service, lifecycle, failure, authority, and NLSpec sprints must
preserve or resolve. It is evidence-only and does not prescribe implementation
changes.

## Open handoff themes

- S4 should convert high-severity external-state hazards into service lifecycle and resource allocation rows.
- S4 may create new service/resource hazard IDs, but this S3 list must cite only existing `HAZ-S3-*` rows until later sprint rows are actually created.
- S5 should define which retained reports/logs are stable machine interfaces versus diagnostics.
- S6 should recover timing, lock, port, and cleanup-on-interrupt behavior from targeted runtime evidence if authorized.
- S8 should settle package script, generated output, and reset route authority.
