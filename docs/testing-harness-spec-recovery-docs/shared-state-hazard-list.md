# Testing Harness Recovery Shared State Hazard List

## Document role

This S3 artifact records fixture, artifact, cleanup, and shared-state hazards
that later service, lifecycle, failure, authority, and NLSpec sprints must
preserve or resolve. It is evidence-only and does not prescribe implementation
changes.
