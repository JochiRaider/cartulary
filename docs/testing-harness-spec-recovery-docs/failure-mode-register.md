# Testing Harness Recovery Failure Mode Register

## Document Role

This S5 artifact registers recurring and plausible caller-visible failure modes
found in S2, S3, S4, and S5 source evidence. Every row states detection,
reporting location, exit/report/artifact surface, retryability, ownership, and
cleanup/artifact/resource follow-up. Runtime-only outcomes remain source-limited
until S6.
