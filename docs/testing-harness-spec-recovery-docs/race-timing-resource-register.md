# Testing Harness Recovery Race Timing Resource Register

## Document role

This S6 artifact classifies race, timing, cancellation, cleanup, and resource
hazards carried from S4. It does not execute runtime commands and does not close
`SL-0012`, `SL-0013`, `SL-0014`, or `SL-0015`.
