Cartulary Entra application ID reference catalog

This advisory catalog contains factual application/client identifiers and names
from selected Microsoft documentation, together with original Cartulary text.
It is not a Microsoft registry, a verified-publisher result, or an authorization
or security verdict. Absence from this catalog establishes none of those facts.

The 139 identities include 20 with selected current-documentation support and
119 supported only by the historical 2025-05-30 snapshot. Historical inclusion
does not establish present naming, ownership, availability or lifecycle status.
Seven source assertions are quarantined; one repeated identity is coalesced.
Shared labels retain distinct IDs and are omitted from ambiguous alias lookup.
No service-principal names or tenant observations are supplied by this release.

Source references identify exact retained research bytes and original line
locators. Copied upstream descriptions, documentation and licensing evidence
are not included in this payload. Original summaries are separately authored;
application names and Microsoft attribution identify documented facts.
